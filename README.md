# Simple Bank System



A simple banking system built with Python using Object-Oriented Programming and Tkinter GUI.



## Features



- Create bank accounts

- Login and logout system

- Deposit money

- Withdraw money

- Show current balance

- Show transaction history

- Delete account
  
- Different account types:

&#x20; - Savings Account

&#x20; - Current Account

&#x20; - Business Account

- JSON file storage for saved accounts



## Technologies Used



- Python

- Tkinter

- JSON

- Object-Oriented Programming



## How to Run



1. Make sure Python is installed.

2. Clone the repository.

3. Run the file:



```bash

python main.py
